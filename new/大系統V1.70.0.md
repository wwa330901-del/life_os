# 大系統 V1.70.0（2026-08-11）

行事曆事件顯示「來自 iCloud」標籤 + 定期定額提醒漏發修正（v2.9.22）。

## 修正

- **行事曆事件看不出來是不是從 iCloud 匯入的**：後端其實一直都有把 `appleEventUid` 傳回來，但 App 端的 `CalendarEvent` model 沒有解析這個欄位，所以連結 iCloud 之後匯入的行程雖然有正確顯示在行事曆上，卻沒辦法像 Google 同步的事件一樣看到「已同步 Google」那種來源標示。現在事件詳情會多顯示「來自 iCloud」。
- **股票定期定額提醒（純後端）漏發、整個月都不會再重試**：原本的寫法是先把「這個月已經提醒過」寫進資料庫，才去發 LINE 推播——如果那次推播剛好失敗（網路問題、伺服器當下重啟、LINE API 暫時出狀況），標記已經寫下去了，系統就誤以為處理過，整個月都不會再檢查這筆，使用者完全收不到通知也不會有任何補救。改成：(1) 推播真的成功才寫入標記；(2) 判斷「今天到了沒」從「剛好等於預定日」放寬成「等於或晚於預定日」，這樣就算某天真的沒觸發成功，隔天的排程會自動補上，不會整個月靜默漏掉。
