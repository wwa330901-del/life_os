# 大系統 V1.34.0（2026-08-03）

延續 V1.33.0，純後端小補充：LINE 新增「改期」指令。

## 使用者需求

「我代辦事項如果有想換時間的我用賴要怎麼換」——查證後 LINE 端從來沒有「修改代辦事項日期」的指令，只有新增/完成，想換日期只能刪除重建。

## 實作

- `LineService` 新增 `改期 編號 新日期(或「持續」)` 指令（例如「改期 2 8/15」「改期 2 持續」），編號沿用跟「完成 N」一樣的 `LineAccountLink.lastTodoListIds` 對照機制。
- 把 V1.32.0 加的日期/「持續」解析邏輯（原本內嵌在 `parseTodoCommand` 裡）抽成共用的 `parseDateOrOngoingPrefix`，`新增`跟`改期`兩個指令共用同一套「數字+/」自我分隔解析，不重複寫。
- `代辦事項`（單一目標）跟`代辦事項總覽`的說明文字都補上「改期」的用法。

## 發布

- 純後端修正（`apps/api`），沒有 Windows App 端變動，不需要版本號、不需要重新編譯安裝檔。
- `npx tsc --noEmit`／`npm test`（51 個測試）全過。
- commit + push，Render 自動部署。
