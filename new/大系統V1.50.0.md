# 大系統 V1.50.0（2026-08-05）

共用行事曆——今天稍早討論、中途暫停去處理財務總覽的那個功能，現在完成。

## 規格（跟使用者確認過的）

- 用 email 邀請別人共用你的行事曆（沿用知識庫封鎖名單同一套 `GET /users/lookup?email=`）。
- **需要對方接受邀請才生效**，不是單方面就能看到——`CalendarShare.accepted` 預設 `false`，只有檢視者自己按接受才會變 `true`。拒絕/移除/撤銷都是直接刪除這筆紀錄，不留「已拒絕」的痕跡，之後要重新邀請就是全新一筆。
- **詳細程度是擁有者的權限，可以隨時調整**：FULL（完整內容）或 BUSY_ONLY（只顯示「忙碌」，不透出標題/地點/備註）。
- **顏色是檢視者自己的顯示偏好**，跟擁有者的分享設定完全無關，固定 8 色調色盤。
- 邀請/接受都不推播 LINE，只在 App 裡看得到（使用者明確選擇的行為）。

## 後端

新模組 `calendar-shares`：`CalendarSharesService`（invite/listGiven/listReceived/accept/updateDetailLevel/updateColor/remove/combinedEvents）+ controller，都掛在 `/calendar-shares` 底下（不像其他行事曆 API 掛在某個 Space 底下，因為這是跨帳戶的關係，不屬於任何一個 Space）。`combinedEvents(viewerUserId, from, to)` 是合併檢視的組裝點：抓自己的行事曆事件，再抓每個已接受分享的擁有者事件，依 `detailLevel` 決定要不要把標題/地點/備註換成「忙碌」，每筆都標上擁有者名字跟檢視者選的顏色。

## App

`CalendarScreen` 標頭新增「顯示共用行事曆」開關跟「共用行事曆設定」按鈕。設定對話框兩個分頁：「收到的分享」（待處理邀請可以接受/拒絕，已接受的可以選顏色、移除）跟「我的分享」（email 邀請、調整詳細程度、撤銷）。開關打開後，右側單日行程面板會多顯示每個已接受分享的當日行程，用檢視者選的顏色標記、附擁有者名字——月曆格子本身維持只顯示自己的行程（範圍考量，沒有重寫整個月曆格子渲染邏輯）。

`tsc --noEmit`、`flutter analyze`、既有 51 個 API 單元測試全過。
