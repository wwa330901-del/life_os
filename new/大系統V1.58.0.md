# 大系統 V1.58.0（2026-08-05，LINE 選單）

LINE 選單改圖：新增知識庫/AI問答/今日行事曆按鈕。

## 內容

原本的選單是 3×3（記帳/財務總覽/股票買賣/持股總覽/代辦事項/代辦總覽/美食/景點/展覽），這次改成 4×3，新增「今日行事曆」「知識庫」「AI 問答」三個按鈕，並按照使用者指定的順序（由左而右、由上而下）重新排列：

記帳、財務總覽、股票買賣、持股總覽、代辦事項、代辦總覽、今日行事曆、知識庫、AI 問答、美食、景點、展覽

視覺風格延續原本選單（深色底、金色線條圖示），三個新按鈕沒有另外標記。

## 技術細節

- 「知識庫」「今日行事曆」點下去送出的文字，後端本來就有對應指令（`text === '知識庫'`、`text === '今日行事曆'`），不用改任何程式碼。
- 「AI 問答」按鈕送出的文字是「查詢」（AI 問答指令的既有觸發字，需要接問題才能真的問，點下去會先看到「請在「查詢」後面接你想問的問題」的提示，這是預期行為）。
- 「代辦總覽」按鈕顯示的標籤是簡稱，實際送出的文字是完整的「代辦事項總覽」（後端只認這個完整字串）。
- 選單圖片（2500×1686）用 Node + sharp 手刻 SVG 產生，不是外部素材；已存一份到 `Visual Design/LINE選單設計V1.png` 留底。
- 透過 LINE Messaging API（`POST /v2/bot/richmenu` 建立 → 上傳圖片 → `POST /v2/bot/user/all/richmenu/:id` 設為所有使用者預設 → 刪除舊選單）直接上線，純操作性質，這個 repo 裡沒有對應的程式碼——跟 Google Calendar 連結一樣，選單本身是 LINE 平台的設定，不是 App/後端功能。

## 發布

純 LINE 平台端設定，沒有程式碼變動，不需要 commit/push 或版本更新。已直接上線生效，所有使用者下次打開 LINE 對話框看到的選單就是新的。
