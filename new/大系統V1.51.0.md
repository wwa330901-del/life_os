# 大系統 V1.51.0（2026-08-05）

借出/借入互通——記錄借給/跟其他元序使用者的錢，對方接受邀請後自動在他自己的帳戶建立對應紀錄。

## 規格

- 每筆借貸可以「邀請對方確認」，用對方的元序帳號 email。
- **需要對方接受邀請才會建立紀錄**（跟共用行事曆同一套設計精神）——邀請送出後不會自動幫對方記帳，要等對方自己在 App 按接受。
- 接受後在對方的個人空間自動建一筆**方向相反**的借貸（我借出去，對方就是借進來），金額/日期/備註照抄，帳戶用對方排序第一個帳戶（沒有更好的預設可選，跟 LINE 記帳指令同一套簡化邏輯）。
- **只在接受當下建立一次，之後兩邊各自獨立**，不會持續同步——之後任一邊登記還款，不會反映到對方那邊。使用者的原話是「對方的帳戶會自動多一筆紀錄」，不是要求雙向即時同步。
- 拒絕（或撤銷還沒被接受的邀請）直接刪除，不留痕跡；已經接受的邀請不能撤銷（兩邊的紀錄已經各自獨立存在）。

## 後端

新的 `FinanceLoanInvite` 表：`fromLoanId`（唯一，一筆借貸只能邀請一次）、`fromUserId`/`toUserId`、`accepted`、`createdLoanId`（接受後建立的對應借貸）。`FinanceLoansService` 新增 `inviteConfirmation`/`listReceivedInvites`/`acceptInvite`/`removeInvite`。送邀請掛在既有的 `/spaces/:spaceId/finance/loans/:id/invite`；收邀請的三個動作（列表/接受/刪除）是新的頂層 `/finance-loan-invites`（不掛在 spaceId 底下，因為接受邀請是「在呼叫者自己的個人空間建一筆」，跟共用行事曆的 `calendar-shares` 同樣的跨空間路由風格）。

## App

借貸卡片新增「邀請對方確認」按鈕（已經邀請過的借貸改顯示邀請狀態：等待中/已接受）；借貸分頁標頭新增「借貸邀請」按鈕（有待處理的顯示數字徽章），點開是收到的邀請列表，可以接受/拒絕。

`tsc --noEmit`、`flutter analyze`、既有 51 個 API 單元測試全過。
