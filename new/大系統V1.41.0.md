# 大系統 V1.41.0（2026-08-04）

## LINE 補上「今日行事曆」查詢指令

使用者：「有一個小問題就是line沒辦法看今天的行事曆」。

**背景**：LINE 的行事曆功能一直只有「新增行事曆」，沒有任何指令可以「看」行事曆內容——記帳有「財務總覽」、代辦事項有「代辦事項總覽」，行事曆卻沒有對應的查詢指令，是個真實的缺口。

**確認的範圍**：只要「今日行事曆」，只看今天，不用查任意日期區間。

**實作**：`LineService.sendTodayCalendarEvents`——找使用者的行事曆空間，用 `taipeiTodayRange()`（同一套台灣時區今日判斷，避免 Render 伺服器 UTC 時鐘造成的偏移）抓今天的 `CalendarEvent`，依時間排序列出（全天活動標「全天」，有地點的附註地點），沒有行程時回「今天沒有排定的行程」。指令說明也加進了「記帳」的看不懂訊息裡。
