# 大系統 V1.45.0（2026-08-05）

記帳分類設定畫面：子分類預設收起。

## 問題

`finance_categories_tab.dart` 的母/子分類列表，過去每個母分類底下的子分類永遠是全部展開顯示，分類一多（尤其收入/支出各自都有好幾個母分類、每個又有好幾個子分類時）畫面會拉得很長，要一直往下捲。

## 修正

`_CategoryGroup` 改成 `StatefulWidget`，自己記一個 `_expanded`（預設 `false`）。母分類這一列點下去（或點展開箭頭圖示）才會展開顯示子分類清單跟「新增子分類」按鈕；母分類本身沒有任何子分類時，不顯示展開箭頭，直接照舊顯示「新增子分類」按鈕（沒有東西好收，不需要多一層點擊）。展開狀態只存在畫面自己的 State 裡，不記憶，每次重新進來這個分頁都是全部收起的乾淨畫面。

`flutter analyze` 全過。

純 App 端小改動，版號升到 2.9.3，隨附安裝檔更新。
