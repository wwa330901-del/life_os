# 大系統 V1.61.0（2026-08-06）

知識庫重新分析 + 來源顯示。

## 內容

- 知識庫項目詳細頁新增「重新分析」按鈕，可以輸入額外指示給 AI（例如「分析多一點」），不輸入就單純重新跑一次分析。
- 詳細頁新增「來源」區塊，不論來源是連結、圖片、影片還是純文字都能看到：連結可點開、圖片直接嵌入顯示、影片給一個開啟原始檔的連結、純文字整段顯示在捲動區塊裡。

## 技術細節

- 新增 Supabase Storage 整合（`SupabaseStorageService`，純 REST API 呼叫，沒有另外裝 SDK）：圖片/影片來源這次開始會把原始檔存進一個 private bucket `knowledge-media`，之前分析完就丟了、完全沒地方能再看/再分析。
- 存檔是 best-effort——Storage 掛掉不會讓分析本身失敗，只是那筆資料之後不能重新分析/顯示來源，跟這次上線之前的行為一樣。
- 「重新分析」根據這則資料原本的來源類型決定怎麼重抓：圖片/影片從 Storage 下載回來，連結重新抓一次網頁，純文字直接重用當初存的內容——不需要使用者重新傳一次。
- 顯示來源用的是短效期（1 小時）簽名網址，不是永久公開連結，符合這個 bucket 私人的設定。

`tsc --noEmit`、既有 60 個 API 單元測試全過，`flutter analyze` 乾淨。

## 發布

後端 + Windows App 都有變動，版號 +1、重新編譯安裝檔並發布 GitHub Release。後端另外需要 Render 環境變數 `SUPABASE_URL`/`SUPABASE_SERVICE_ROLE_KEY`（已設定）。
