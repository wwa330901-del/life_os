# 大系統 V1.68.0（2026-08-07）

新增工作代辦事項預設指派給自己（v2.9.20）。

## 背景

代辦事項有一套「同步到行事曆」的機制（2026-08-05 就有了）：有到期日/時間的代辦事項會自動在負責人的行事曆空間建立對應行程。但工作代辦的「指派給」下拉選單預設是空的（未指派），沒有負責人就沒有同步目標，代辦事項不會出現在任何人的行事曆上——使用者容易忘記手動選，然後納悶「代辦事項怎麼沒同步到行事曆」。

## 修正

新增（不是編輯既有的）工作代辦事項時，「指派給」預設帶入自己——前提是自己確實是這個專案的成員（避免下拉選單選到一個不在成員清單裡的值）。要指派給別人還是可以直接改下拉選單。
