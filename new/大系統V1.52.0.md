# 大系統 V1.52.0（2026-08-05，純後端）

投資交易入帳記帳系統時自動套用分類。

## 問題

`StocksSettlementService` 交割時建立的記帳交易從來沒有設定 `categoryId`，導致每一筆股票買賣交割入帳都是「未分類」，看不出來、財務總覽/預算都抓不到。

## 修正

- `DEFAULT_CATEGORIES`（記帳分類第一次進去時的預設種子）新增「股票買」（支出）「股票賣」（收入）兩個母分類。
- `FinanceCategoriesService` 新增 `findOrCreateSystemCategory`——查不到就自動建立，不需要一次性的資料回填腳本：不管這個空間是全新的（已經被種子帶出來）還是早就存在（沒有這兩個分類），第一次真的交割股票時都會自動補上。
- `StocksSettlementService` 交割時呼叫這個方法拿到分類 id，設到建立的 `FinanceTransaction.categoryId` 上——買入自動套「股票買」，賣出自動套「股票賣」，使用者不用手動選。

`tsc --noEmit`、既有 51 個 API 單元測試全過。

## 發布

純後端修正，Windows App 端沒有任何程式碼變動（交易列表/財務總覽本來就會顯示 `categoryId` 對應的分類，這次只是後端終於有填這個欄位）——不隨附安裝檔更新，直接 commit + push 讓 Render 重新部署即可生效。
