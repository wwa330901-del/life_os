# 大系統 V1.59.0（2026-08-06）

好友功能。

## 設計

新增 `Friendship`（邀請+接受，雙方互為好友，跟共用行事曆/借出借入互通同一套「拒絕=直接刪除，不留痕跡」設計）。這是共用行事曆邀請、借出/借入互通邀請這兩個既有功能的前置條件——2026-08-06 起，這兩個功能都改成必須先是好友才能邀請，選人時直接從好友列表點選，不再打對方 email。

- `FriendsService.assertFriends(userId, otherUserId)`：共用行事曆/借出借入互通的邀請流程都靠這個把關。
- `CalendarSharesService.invite`、`FinanceLoansService.inviteConfirmation` 都從「吃 email」改成「吃對方 userId」。
- App 側邊欄新增「好友」入口（好友列表 + 移除、收到/送出的邀請 + 接受/拒絕/撤銷、用 email 邀請新好友）。
- 共用行事曆的「邀請」按鈕、借出/借入互通的「邀請對方確認」按鈕都改成跳出好友選單；沒有好友時會提示先去加好友。

`tsc --noEmit`、既有 60 個 API 單元測試全過，`flutter analyze` 乾淨。

## 發布

後端 + Windows App 都有變動（`POST /calendar-shares/invite`、`POST .../finance/loans/:id/invite` 的 body 從 `{email}` 改成 `{viewerUserId}`/`{toUserId}`），版號 +1、重新編譯安裝檔並發布 GitHub Release。
