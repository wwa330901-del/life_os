# 大系統 V1.27.0（2026-08-02）

延續 V1.26.0，同一天修正導覽一致性問題，發布 `v2.2.1`。

## 使用者反饋

「知識庫也是一個空間，他跟私人空間、公司空間、行事曆是平行的」——追問後確認具體問題：「因為左側導覽列找不到知識庫，再知識庫也不能切換空間」。

v2.1.1 把知識庫改成首頁的獨立卡片後，產生了新的落差：
- 知識庫頁面本身沒有側邊欄，離開只能靠「回首頁」。
- 人在某個空間裡時，側邊欄找不到任何入口可以直接跳去知識庫，只能先回首頁再點知識庫卡片。

## 實作

把「空間列表＋回首頁」那段共用邏輯抽成一個獨立元件 `SpaceSwitcherList`（`apps/windows_app/lib/ui/shell/space_switcher_list.dart`），內容是：所有空間 + 知識庫 + 回首頁，三種目的地互相都能直接切換：

- `AppSidebar`（空間內的側邊欄）帶入 `selectedSpaceId`，用同一份列表，現在多了「知識庫」這一行。
- `KnowledgeShell`（知識庫頂層畫面）新增自己的側邊欄，一樣用這份列表，帶入 `knowledgeSelected: true`。

之後如果再多一個跟空間平行的頂層目的地，比照這個模式擴充 `SpaceSwitcherList` 就好，不用重複寫一次列表邏輯。
