# 大系統 V1.72.0（2026-08-12）

定期定額新增「立即檢查」按鈕，補上每期金額後不用等隔天早上 9 點排程（v2.9.24）。

## 背景

使用者發現 8 月建立的定期定額計畫因為舊版 bug 沒收到通知，問能不能補資料。「每期投入金額」是必填欄位、只有計畫主人自己知道，沒有直接存取權可以代填。討論後決定：讓使用者補上金額後，可以自己手動觸發一次到期檢查，不用乾等隔天排程。

## 新增內容

- 後端新增 `POST /stocks/recurring/:id/check-now`：檢查計畫啟用中、有設定每期金額、沒有已在等回覆的交易、這個月還沒處理過、扣款日已經到了，通過就立刻建一筆待填成交價的交易並發 LINE 提醒（跟每日排程走同一套邏輯，抽成共用方法 `createPendingAndNotify`)。
- App 定期定額分頁：計畫卡片上（沒有等待回覆、已設定金額、啟用中時）顯示「立即檢查」按鈕，點下去呼叫新 API，成功後即時刷新畫面。

## 發布

`tsc --noEmit`、既有 60 個單元測試全過、`flutter analyze` 乾淨（僅既有的 info 等級提示，無錯誤）。確認 Render 上 v2.9.23 的兩個資料庫更新（`stock_recurring_monthly_amount`、`stock_transaction_pending_dca`）已套用（`npx prisma migrate deploy` 顯示無待處理項目）。version 2.9.23 → 2.9.24，clean build + 安裝檔重新打包。

## 使用方式

計畫卡片上點「立即檢查」（重新整理圖示）——已補上每期金額、這個月扣款日已到、還沒被處理過的計畫，點了會立刻建好待填成交價的交易並發 LINE 提醒，接下來一樣要「登記成交」填成交價才算完成。
