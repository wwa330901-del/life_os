# 大系統 V1.39.0（2026-08-04）

## 展覽提醒安排時一併補上代辦事項

使用者：「補上去吧代辦已經獨立出來了就執行」。

**背景**：LINE 展覽提醒（`resolveExhibitionSchedule`）原本使用者回「安排」+ 時間之後，只會寫入一筆 `CalendarEvent`，不會建立代辦事項——當初是因為 `ProjectTodo.projectId` 是必填、展覽又不屬於任何專案，沒辦法建立。個人代辦事項（`personalOwnerUserId`）獨立出來之後這個限制已經不存在。

**實作**：在建立 `CalendarEvent` 之後，同一支方法再多寫一筆個人代辦事項（`personalOwnerUserId: link.userId`），標題為「觀展：{展覽名稱}」，`dueDate` 用同一個使用者回覆的安排時間，`isOngoing: false`，`sortOrder` 沿用既有「抓這個人代辦事項目前最大 sortOrder + 1」的寫法（跟 LINE「新增代辦」指令用的是同一套邏輯）。安排完成的回覆訊息也一併更新，告知「加進你的行事曆和代辦事項了」。
