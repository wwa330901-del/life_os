# 大系統 V1.56.0（2026-08-05）

借貸/代墊還款單筆編輯 UI。

## 問題

`FinanceLoansService.updateRepayment`/`FinanceAdvancesService.updateRepayment` 後端本來就支援編輯單筆還款/收回紀錄（`PATCH .../repayments/:id`），但 App 端一直沒有對應的操作介面——卡片上只顯示「已還款 N 筆，共 X」的總計，看不到、也改不了個別那一筆。

## 修正

- 借貸/代墊卡片把原本只有總計的一行，展開成每一筆還款/收回都列出來（日期、金額、帳戶、備註），每一筆旁邊加一個小編輯圖示。
- 點下去開「編輯還款／編輯收回」對話框，金額/帳戶/日期/備註都預先帶入現值可改，送出後呼叫既有的 `updateFinanceLoanRepayment`/`updateFinanceAdvanceRepayment`（都是既有 API，這次只是補上呼叫它的介面）。
- 超過本金的驗證維持後端把關（跟編輯借貸本金同一套錯誤處理），App 端不重複做前端驗證。

`flutter analyze` 乾淨（後端這次沒有變動）。

## 發布

只有 Windows App 端變動——版號 +1、重新編譯安裝檔並發布 GitHub Release。
