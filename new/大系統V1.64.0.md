# 大系統 V1.64.0（2026-08-07）

工程財務四表模組（v2.9.17）— App 端畫面，接續 V1.63.0 的後端。

## 新增

專案詳情頁新增第五個分頁「工程財務」，底下再分四張表：

- **工程報價單**：工項列表（單價/數量/成本單價/複價/成本複價/利潤/毛利率），支援新增/編輯/刪除，跟「設定目標毛利率／目標總金額」一次性回推單價。
- **採發比價表**：可以開多張（每張對應一個發包範圍），每張底下多家廠商報價比較，可上傳廠商報價附件（沿用知識庫的 Supabase Storage）、選定得標廠商。
- **成控管制表**：每一列可以勾選多筆報價單工項分組（一個工項只能被一列勾選，避免業主報價/預估成本重複加總），可連結一張採發比價表帶入實際發包金額，顯示業主報價/預估成本/實際發包/追加減/合約金額/已請款進度，支援新增追加/追減紀錄跟拆項表匯出（跳窗顯示這一列勾選的工項明細）。
- **工程請款單**：對應一列成控列，送出時指定五關簽核人（業務主管/財務初審/成控/總經理/會計出納），畫面上依序顯示每一關狀態，輪到自己的那一關可以直接核准/退回。
