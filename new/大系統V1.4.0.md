## 四、目前已完成功能

### 平台核心

- 帳號系統：註冊需填 **姓名 / 帳號（username，3-20 碼英數與底線）/ Email / 密碼（至少 6 碼）**
- 登入採「帳號＋密碼」，不是 Email＋密碼
- Email 驗證：註冊後用 Resend 寄 6 碼驗證碼，未驗證不能登入，可重新寄送
- Google 登入：OAuth「Desktop app」類型 + loopback redirect（RFC 8252），client_secret 只存在後端環境變數，不會出現在發布的桌面程式裡
- 個人空間自動建立；公司空間會員關係骨架（角色分 OWNER / ADMIN / MEMBER）
- 所有空間存取權限都在後端檢查，不是前端藏按鈕

### 視覺設計

- 圍繞「沐晞而醒、等待而休、歸來而安、映曛而行」這首詩發想出一套**統一**的暖色系視覺主題（`AppTheme`），不是四套切換式主題；後來詩句文字從畫面上拿掉，只留配色與漸層氛圍
- 登入頁：晨光漸層背景。首頁：歸家漸層頁首。第三種「暮色」漸層保留給未來模組導覽用

### 桌面整合與自動更新

- Inno Setup 安裝程式（`installer/life_os.iss`）：per-user 安裝（不用系統管理員權限）、自動建立開始功能表項目與桌面捷徑
- App 每次開啟會自動檢查 GitHub Release 有沒有新版本，使用者選「現在更新」會**全自動**下載安裝檔、背景靜默安裝、裝完自動重開 App，不需要使用者手動點安裝檔
- Windows CMake 加了 `/utf-8`、Inno Setup 腳本加了 `#pragma code page 65001`，確保「元序」等中文字在原生視窗標題與安裝程式裡正確顯示（不會因為系統編碼問題變亂碼）

### 正式環境部署

- **API**：Render 免費方案，網址 `https://life-os-api-yhh2.onrender.com`。閒置一段時間會休眠，下一次請求要等 30-60 秒喚醒
- **資料庫**：Supabase PostgreSQL 免費方案。連線必須用 **Session Pooler**（`aws-0-<region>.pooler.supabase.com:5432`），不能用 Direct Connection——Supabase 免費方案的 Direct Connection 只給 IPv6，大多數雲端平台的對外連線連不上
- **寄信**：Resend 免費方案（3000 封/月）
- **Google OAuth**：Google Cloud Console 專案（project id 開頭 `life-`），OAuth 同意畫面已從「測試中」發布為「正式版」；因為只用到非敏感 scope（openid / email / profile），不需要 Google 審核就能讓任何 Google 帳號登入

## 五、已知限制（尚待解決）

1. **Resend 寄信限制**：免費帳號目前只能把驗證信寄給當初申請 Resend 帳號用的那個信箱（`wwa330901@gmail.com`），其他任何人拿自己的信箱走「帳號密碼註冊」都會卡在收不到驗證信這步。要解決需要去 Resend 驗證一個自訂網域，把寄件位址換成該網域的信箱。**這是目前唯一還沒解決、會擋住「除了你以外的人用密碼註冊」的問題**（Google 登入不受影響，因為不需要寄信）。
2. Render 免費方案閒置會休眠，首次喚醒的 30-60 秒對使用者來說像卡住，之後要更好體驗需升級付費方案或換平台。
3. 尚未做角色/欄位層級的細緻權限規則，目前只有 OWNER/ADMIN/MEMBER 這種粗粒度角色。
4. reno_pm 的甘特圖/工期管理邏輯尚未搬進來。
5. 尚無 LINE 串接、AI 功能（維持 V1.2 決議：第一階段排除）。
