# 大系統 V1.55.0（2026-08-05）

股票定期定額 App 端登記成交介面。

## 問題

定期定額（DCA）計畫到期只會發 LINE 提醒，使用者一定要回 LINE 文字「代碼 成交價 投入成本」才能記一筆股票交易，App 端完全沒有對應的操作介面——如果剛好不方便用 LINE，就只能等。

## 修正

- `StocksRecurringService` 把原本 LINE 專用的成交建立邏輯拆成共用的 `doFulfill()`：`fulfillPendingReply(spaceId, stockCode, ...)`（LINE 用，找目前正在等待該股票代碼回覆的計畫）跟新增的 `fulfillById(userId, spaceId, id, ...)`（App 用，畫面上已經知道是哪個計畫，直接用 id 查）兩邊都呼叫它，行為完全一致（建立 `StockTransaction`、清除 `awaitingReply`、`recompute` 持股快取）。
- 新增 `POST /spaces/:spaceId/stocks/recurring/:id/fulfill`，body 是 `{pricePerShare, totalCost}`；只有 `awaitingReply === true` 的計畫才能登記，否則回 400。
- App「定期定額」分頁：等待回覆中的計畫卡片上會多一個「登記成交」按鈕，點下去問成交價／投入成本（即時算出約幾股），送出後同時刷新定期定額列表、股票交易紀錄、持股總覽三個畫面。

`tsc --noEmit`、既有 51 個 API 單元測試全過，`flutter analyze` 乾淨。
