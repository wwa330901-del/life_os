# 大系統 V1.49.0（2026-08-05）

記帳「總覽」補成一份正常的財務報告；預算加上總和。

## 問題

使用者反應個人記帳的「總覽」太簡陋，只有本月收入/支出/淨額卡片、支出分類佔比餅圖、預算進度——完全看不出「整體財務狀況」：沒有跨帳戶的總資產、沒有跨月份的收支趨勢、預算也沒有加總只能一筆一筆自己心算。

## 修正

- **總資產卡片**：加總所有帳戶的餘額，顯示在總覽最上方（不受月份選擇器影響，永遠是「現在」的總資產，帳戶數量一起顯示）。
- **近 6 個月收支趨勢**：新增後端 `GET /spaces/:spaceId/finance/transactions/trend?months=6`，用資料庫端 `aggregate` 分月加總收入/支出（不是整批撈交易再加總，跟其他「無上限查詢」修法同一個原則）。App 端用 `fl_chart` 的 `BarChart` 畫成收入/支出並排長條圖，一眼看出花費是在增加還是減少。
- **預算總和**：預算進度清單最上面加一張「全部預算」卡片，加總所有分類的預算金額跟本月花費，一樣有進度條跟超支變色。

`tsc --noEmit`、`flutter analyze`、既有 51 個 API 單元測試全過。
