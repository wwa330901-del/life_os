# 大系統 V1.67.0（2026-08-07）

新增專案不再強制填「簽約日期」（v2.9.19）+ 工程財務四表部署問題修正（純後端）。

## 修正

- **KnowledgeModule 忘記 export SupabaseStorageService**：這是 v2.9.17（工程財務四表）一直沒辦法真的部署上線的根本原因——`EngineeringFinanceModule` 需要注入 `SupabaseStorageService`，但 `KnowledgeModule` 只把它註冊成 provider、沒有加進 `exports`，導致 NestJS 每次啟動都直接掛掉，Render 只能一直留在舊版本，怎麼點 Manual Deploy 都沒用。修好後已確認正式環境路由正常。
- **新增專案不再要求先填「簽約日期」**：這個欄位其實是系統內建、排程引擎用的「工期起算基準日」（不是使用者自訂欄位），被同時當成兩種不同概念在用——很多專案新增當下根本還沒簽約，也還沒有實際開工日可填。新增專案時直接帶入今天，不用使用者填；之後真的要調整，一樣可以到「專案資料」分頁改。
