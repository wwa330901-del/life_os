# 大系統 V1.60.0（2026-08-06）

財務分析報表。

## 內容

個人記帳新增「報表」分頁，七大區塊：

- **淨資產與趨勢**：總資產（帳戶餘額＋持股市值＋我借出/代墊出去未收回的錢）－總負債（我借入未還清的錢），每天存一筆快照累積出趨勢線。
- **儲蓄率**：本月（收入－支出）÷收入。
- **分類支出佔比與趨勢**：本月圓餅圖 + 前三大分類近 6 個月走勢。
- **投資組合配置與年化報酬率**：持股市值佔比圓餅圖，每檔的報酬率跟簡化年化報酬率（用「離這檔最早一筆交易的天數」換算，不是嚴謹的 XIRR，但對個人記帳規模是合理近似）。
- **異常/超支摘要**：超出預算的分類、本月支出比上月變化百分比。
- **借貸/代墊總覽**：別人欠你、你欠別人、代墊未收回，一次看完。
- **最大支出排行榜**：本月前 10 筆最大支出。

## 技術細節

- 淨資產沒辦法回溯歷史（帳戶餘額/持股都不是有版本紀錄的資料），趨勢只能從這個功能上線那天開始累積——新增 `FinanceNetWorthSnapshot` 表，每天一筆，凌晨 cron 補全部空間，`getReport()` 本身也會自我修復當天缺的那筆。
- 新增 `FinanceReportModule`，沒有直接掛進 `FinanceModule`——`StocksModule` 已經反過來 import `FinanceModule`，報表又需要 `StocksHoldingsService`，所以獨立一個更上層的模組同時 import 兩邊，避免循環依賴。
- 其他六塊都是重用既有的帳戶/交易/預算/借貸/代墊/持股 service，沒有另外複製一份查詢邏輯。

`tsc --noEmit`、既有 60 個 API 單元測試全過，`flutter analyze` 乾淨。
