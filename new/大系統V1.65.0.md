# 大系統 V1.65.0（2026-08-07）

代辦事項逾期提醒補齊 + 知識庫重新分析卡住修正（v2.9.18）。

## 修正

- **LINE 代辦事項通知/代辦事項總覽漏掉逾期項目**：`HomeService.getTodosToday` 之前只抓「剛好今天到期」的未完成代辦，早於今天的逾期項目雖然有查到卻沒有被放進任何顯示區塊，等於憑空消失。現在補上 `overdueIncomplete`，LINE 早/晚安提醒跟「代辦事項總覽」都會多一段「⚠️ 已逾期未完成」，排在最前面。
- **知識庫「重新分析」卡在載入畫面不會結束**：App 端只捕捉 `ApiException`，但重新分析（尤其圖片/影片）耗時較長，中途連線逾時/中斷時 http 套件丟出的是別種例外，沒被抓到，導致載入視窗永遠關不掉——即使後端其實已經跑完、LINE 也收到完成通知了。改成不管什麼例外都要關閉視窗並重新整理畫面。順便查過全 App，這是唯一一個「阻擋式載入視窗 + 只抓 ApiException」的地方，沒有其他地方有同樣問題。

`tsc --noEmit`、既有 60 個 API 單元測試全過；`flutter analyze` 乾淨。version 2.9.17 → 2.9.18，clean build + 安裝檔重新打包。
