# 資料還原說明

正式資料庫每天台北時間 02:30 自動備份（`.github/workflows/db-backup.yml`），加密後在 GitHub 保留 30 天。每次備份都會先實際還原到一個空資料庫，確認檔案是好的。備份失敗或超過 36 小時沒成功，系統會傳 LINE 通知管理員。

## 要還原時

需要：建立備份時設定的 `BACKUP_PASSWORD`、PostgreSQL 17 的 `pg_restore`、GitHub CLI。

1. 列出備份，找要用的那一次：
   ```
   gh run list --workflow=db-backup.yml --status=success
   ```
2. 下載：
   ```
   gh run download <run 編號>
   ```
3. 解密（會問密碼）：
   ```
   gpg --output life_os.dump --decrypt life_os.dump.gpg
   ```
4. 先在 Render 暫停 `life-os-api`，避免還原途中有新資料寫入。
5. 還原到資料庫（會覆蓋 public 底下的所有資料）：
   ```
   pg_restore --clean --if-exists --no-owner --no-privileges --dbname="<連線字串>" life_os.dump
   ```
6. 重新啟動 `life-os-api`，用 App 登入確認資料。

## 注意

- `BACKUP_PASSWORD` 忘了，備份就打不開，要另外記好。
- 資料庫裡的 AI 金鑰、iCloud 密碼、Google 授權是用 Render 上的 `DATA_ENCRYPTION_KEY` 加密的。這個值換掉或遺失，還原後這些要重新設定；其他資料不受影響。
- 解密後的 `life_os.dump` 是沒有加密的完整資料，用完就刪掉。
