# 軟體健檢報告 — 2026-11-09（第 2 次）

評估時版本：App v2.10.30（後端 28b5019）

## 使用者的提問

每次健檢都照這 7 題，以專業的角度和一個生活平凡的人的角度來看：
1. 這套軟體對人生有什麼幫助
2. 可以如何運用這套軟體
3. 這套軟體有哪些可以改進的地方
4. 可以再如何更新這套軟體
5. 這套軟體的實質幫助會有多少估值
6. 如果你是使用者會如何運用這套軟體
7. 這套對你來說有多少分，滿分 100

這次另外要評：
- 有沒有達到人性化、操作簡單明瞭
- 功能有沒有達到三個需求：可以記錄生活大大小小的事、可以幫助我成長、可以透過系統輔助生活跟工作

**這次的依據**：實際看程式、畫面結構和 10/13 之後的更新紀錄。
**這次看不到的**：正式環境的「功能使用次數」，所以無法判斷哪些功能實際沒人用（而且要到 2027-01-11 滿 90 天才準）。

## 特別評估：人性化與操作

**總評：LINE 很人性化（88 分），App 畫面還不夠簡單（68 分）。**

### 做得好的
- 在 LINE 用講的就好，打字、語音、拍收據都行，不用記指令。
- 動到錢或刪除之前一定先確認，不怕 AI 亂改。
- 提醒可以自己打時間延後，每個提醒的按鈕都不會消失（這次新增）。
- 可以回覆某一則訊息，AI 想的時候有「正在輸入」（這次新增）。
- AI 出問題時會用中文講原因，例如額度用完、金鑰無效。
- App 有 41 處空白畫面說明，沒資料時不會只看到一片空白。

### 不夠好的（照影響大小排）

| # | 問題 | 實際情況 |
|---|---|---|
| 1 | 記帳畫面太擠 | 一排 12 個分頁：總覽、規劃、交易、帳戶、分類、預算、定期交易、借貸、代墊、購物車、退休、報表。第一次看會不知道從哪裡開始 |
| 2 | 錯誤訊息還有英文 | 後端有 32 則英文錯誤，包含登入失敗的「Invalid username or password」；欄位檢查的錯誤訊息也是英文 |
| 3 | 錯誤會直接顯示系統原文 | 有 56 處把技術錯誤原文直接顯示在畫面上 |
| 4 | 「空間」是公司版留下的概念 | 還要先選空間才進得去記帳、行事曆，一般人不會這樣想事情 |
| 5 | 沒有新手引導 | 第一次打開沒有帶你設定帳戶、綁 LINE 的步驟 |
| 6 | 圖示按鈕沒有文字說明 | 75 個圖示按鈕、42 個滑鼠停留說明，有不少按之前猜不出用途 |
| 7 | iPhone 只能用 LINE | 沒有 iPhone App，要看報表得回電腦或安卓平板 |

## 特別評估：三個需求

| 需求 | 達成度 | 一句話 |
|---|---|---|
| 1. 記錄生活大小事 | **85%** | 記得很齊，但要找回來還不夠方便 |
| 2. 幫助我成長 | **70%** | 有目標和回顧，但跟每天要做的事沒有接起來 |
| 3-1. 輔助生活 | **88%** | 最強的部分 |
| 3-2. 輔助工作 | **50%** | 最弱的部分 |

### 需求 1：記錄生活大小事（85%）
- **已有**：錢（記帳、股票、借貸、代墊、信用卡）、時間（行程、代辦）、心情（日記）、身體（健康、睡眠）、知識（連結、圖片、影片）、人和事（記住的事、生日紀念日）、旅行。入口有打字、語音、拍照、連結。
- **缺口一：很難跨類別找回來。** 「我上次換機油是什麼時候？」這種問題，目前只有日記能用關鍵字搜尋；記帳明細只能一個月一個月查，代辦沒有搜尋條件。記得進去但找不回來，記錄的價值會少一半。
- **缺口二：日記只能存文字**，存不了照片。

### 需求 2：幫助我成長（70%）
- **已有**：人生目標能自動追蹤（存款、淨資產、持股、打卡）、AI 會幫你把想法變成具體目標、週回顧和月回顧、每晚問日記、財務健檢分數。
- **缺口一：目標跟代辦沒有連結。** 代辦的資料裡沒有「屬於哪個目標」，所以系統知道你落後，卻不知道你做了哪些事推進它。
- **缺口二：回顧偏報告。** 看完有數字和 2～3 句 AI 總結，但沒有「那下一步要改什麼」的環節，看完就結束了。
- **成長最終要看實際使用**，這次看不到使用資料，所以這項給得比較保守。

### 需求 3：輔助生活跟工作
- **生活（88%）**：行事曆和 Google、iPhone 雙向同步，早報、繳費、還款、紀念日都會提醒，還有財務規劃和退休試算。
- **工作（50%）**：公司空間拆掉之後，工作只剩通用的東西：代辦、行事曆、代墊、AI 排工作時段。代辦沒有分工作和私人，也沒有專案、客戶的概念。
- 專案裡的「Document Form」資料夾放著室內裝修的報價單、合約、請款單、成控表，這些工作文件目前跟系統完全沒連起來。
- 拆掉公司空間是之前的決定，所以這不算壞掉，但照「輔助工作」這個需求來看，這裡確實是缺口。

## 1. 這套軟體對人生有什麼幫助

**一般人的角度**
- **錢看得清楚**：帳戶、卡費、借出去的錢、股票，一句話問得到。
- **事情不會忘**：時間到 LINE 會叫你，現在也能自己決定延到什麼時候。
- **比較像在跟人講話**：可以回覆某則訊息說「這筆改一下」，不用重講一遍。
- **知道自己有沒有進步**：目標自動追蹤，加上週回顧和月回顧。

**專業的角度**
它最大的價值仍然是把財務、時間、目標、知識和反思串在一起，再用 AI 當單一入口。目前後端約 2.8 萬行、45 張資料表、90 多個 AI 工具，廣度遠超過一般個人軟體。接下來的瓶頸不是功能不夠，而是資料的安全和實際使用的驗證。

## 2. 可以如何運用

| 時間 | 做什麼 |
|---|---|
| 每天早上 | 看 8 點早報 |
| 隨時 | LINE 講話記帳、記事；提醒來了按完成，或按延後打時間 |
| 想改之前的東西 | 長按那則訊息按「回覆」，直接說要改什麼 |
| 每天晚上 | 回日記提問，三兩句就好 |
| 每週日 | 看週回顧，決定一件下週要調整的事 |
| 每月 1 號 | 看月回顧和財務健檢分數 |

## 3. 可以改進的地方

最重要的三點：
1. **資料庫還是沒有自動備份。** 這是目前最大的風險，所有記錄都在一個資料庫裡，出事就全沒了。
2. **很多功能沒有在真實環境跑過。** 轉帳、財務規劃、學貸、期初代墊，加上這次的 LINE 新按鈕和回覆訊息，都只有程式測試。
3. **App 畫面要簡化。** 英文和技術錯誤訊息、12 個分頁、「空間」的概念。

其他：
- 記帳還是要自己講或拍照，沒有電子發票自動匯入。
- 跨類別搜尋、目標連結代辦、代辦分工作和私人（見上面特別評估）。
- `line.service.ts` 一個檔案超過 3000 行，以後改 LINE 的東西容易互相影響。

## 4. 之後可以怎麼更新

1. **先做安全**：自動備份、獨立的加密金鑰。
2. **再做簡單**：錯誤訊息全中文、記帳分頁重新分組、拿掉「空間」的說法。
3. **補需求缺口**：一句話找回過去的記錄、目標跟代辦連起來、代辦分工作和私人。
4. **工作要做到什麼程度，要使用者決定**：只要分類和提醒就夠，還是要把報價、請款、成控帶回來。
5. **減少輸入**：電子發票自動匯入。

## 5. 實質幫助的估值

- **對個人**：跟上次一樣，**一年約 NT$3～10 萬**。這次沒有實際使用資料，所以不往上調。
- **請外包做一樣的**：約 **NT$150～400 萬**，6～12 個月。
- **當商品的市場價值**：使用者仍然很少，**商業價值接近 0**。

## 6. 如果我是使用者會怎麼用

1. LINE 隨手記帳、記事、提醒（每天）。
2. 早報和週回顧（每天 30 秒、每週 5 分鐘）。
3. 只留 2～3 個目標，每個都用自動追蹤。
4. 每個月看一次財務健檢分數。
5. App 只拿來看報表和做規劃，平常都用 LINE。
